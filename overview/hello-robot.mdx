Create an environment, add an SO-101 digital twin, and explore its controls in simulation. You need a Cyberwave account and a browser; no physical robot is required.

## Follow the walkthrough

<Steps>
  <Step title="Create an environment">
    Go to the [Cyberwave dashboard](https://cyberwave.com/dashboard)
    and click **Blank environment** below the scene prompt. Give it a name
    (e.g. "Hello Robot"), then click **Create environment**. A description is
    optional and lives under **Advanced Options**. **From template** is a
    separate path for starting with a prepared scene.
  </Step>
  <Step title="Add a digital twin">
    Finish or dismiss the editor tour first. In the empty scene, click
    **Add from Catalog**, or use **Add to scene (+) → Add from Catalog**.
    Select the [SO-101 from The Robot Studio](https://cyberwave.com/the-robot-studio/catalog/so101),
    whose registry ID is `the-robot-studio/so101`. Search for **SO101** in the
    picker and check the asset identity before adding it; similarly named
    imported variants can have different joints and controls.
  </Step>
  <Step title="Choose the simulation engine">
    In the top bar of the environment editor, switch from **Edit** to
    **Simulate**, then open **Simulation setup** (or the **Simulate** menu).
    Choose **MuJoCo** for higher-fidelity server physics, click
    **Start Simulation**, and wait for the run to report **Running** before
    sending commands. Entering Simulate alone does not start a MuJoCo run.

    For an optional lightweight browser preview, select **Playground Mode**
    and turn on **Enable Physics**. Playground runs in the browser and has
    limited physics; it does not require a cloud run. A stopped historical
    MuJoCo run is separate from Playground's current physics state.
  </Step>
  <Step title="Open the robot's controls">
    Select the SO-101 in the scene tree and open its **Commands** panel.
    The canonical asset can inherit keyboard controls from its asset setup;
    use those controls when present instead of assigning a second controller.
    If keyboard controls are missing, open **Workbench → Controllers** and
    inspect the robot's assigned controls. A panel offering only
    **Enter joint values** is a joint-target interface, not the keyboard
    control panel; check that you added the intended asset.
  </Step>
  <Step title="Move the robot">
    Activate the robot's keyboard controls and use the bindings displayed
    in that panel. Move focus out of text fields before pressing a binding.
    Double-click the scene-tree row outside its name to frame the robot.
    Confirm that the arm moves in the viewport and its joint readings change.
    Stop the MuJoCo run when finished, or turn off Playground physics.
  </Step>
</Steps>

<Check>
  Continue once you have observed joint motion using the selected engine.
  From here you can explore different controllers, add cameras, or connect
  real hardware.
</Check>
