## Overview

The Cyberwave skill is one cross-agent entrypoint for environments, workflows, robot control, monitoring, edge setup, asset onboarding, and driver development.

It chooses the execution plane for the operation:

- **Cyberwave MCP** for typed cloud context, environment/workflow authoring, monitoring, and planned robot control
- **Cyberwave CLI** for local installation, pairing, edge services, drivers, workers, media devices, and logs
- **SDK/local files** for application code and hardware-driver repositories
- **Dashboard/user steps** for registration, identity, permissions, billing, and other human-owned decisions

## Installation

Clone the canonical public skill directly into Claude Code's global skill directory:

```bash
git clone https://github.com/cyberwave-os/cyberwave-skill ~/.claude/skills/cyberwave
```

For project-local discovery:

```bash
git clone https://github.com/cyberwave-os/cyberwave-skill .claude/skills/cyberwave
```

## Usage

In any Claude Code session, run:

```
/cyberwave
```

Describe what you want to build and Claude will guide you through environment setup, interface selection, and implementation.

## Requirements

- An Agent Skills-compatible client such as Claude Code or Codex
- A Cyberwave account ([sign up](https://cyberwave.com))
- Python 3.11+ and FFMPEG (for the Python SDK path)
