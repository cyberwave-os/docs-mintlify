## The platform at a glance

**AI agents on top, your robots at the bottom, Cyberwave in between.** Agents plan and configure; perception models, controllers and learned policies act through digital twins. Cyberwave Edge connects the twins to real hardware. You get in through the dashboard, the Python SDK, the CLI, REST and MQTT, or MCP.

<img src="/images/cyberwave-architecture.png" style={{ width: "100%", height: "auto", borderRadius: "20px" }} alt="Cyberwave architecture. AI agents on top build the environment, control robots and define workflows. Below them your AI: perceive, control, learn. Then the Cyberwave platform: digital twins and environments, simulation, controllers and handover, catalog, data and training. Then Cyberwave Edge: Edge Core, drivers and workers on Raspberry Pi, Jetson, x86 or macOS. At the bottom your hardware: arms, quadrupeds, rovers, drones, cameras and sensors. Ways in: dashboard, Python SDK, CLI, REST and MQTT, MCP." />

## What it looks like in code

<Tabs>
  <Tab title="Move a robot">
```python
# pip install cyberwave   ·   export CYBERWAVE_API_KEY=...
import time
from cyberwave import Cyberwave

cw = Cyberwave()
arm = cw.twin("the-robot-studio/so101")   # creates or reuses "Quickstart Environment"
cw.affect("playground")                   # free browser simulation; "live" for the real robot
arm.policy.ensure_attached()              # the SDK takes control of the twin
time.sleep(2)
arm.joints.set("shoulder_pan", 45, degrees=True)
print(arm.joints.get())
```
  </Tab>
  <Tab title="Add a model">
```python
# pip install "cyberwave[ml]" opencv-python
import cv2
from cyberwave import Cyberwave

cw = Cyberwave()
model = cw.models.load("yolo26n.pt")      # from the catalog, runs locally
ok, frame = cv2.VideoCapture(0).read()    # your laptop webcam
result = model.predict(frame, confidence=0.5)
print(result.describe())                  # detections with labels and scores
# Next: pick and sort what the camera sees -> /overview/first-ai-loop
```
  </Tab>
  <Tab title="Ask the control agent">
```python
from cyberwave import Cyberwave

cw = Cyberwave()
go2 = cw.twin("unitree/go2")
env = go2.environment_id

plan = cw.agents.control.plan(env, "Move the Go2 to waypoint A", twin_uuid=go2.uuid, mode="simulation")
actions = plan.get("dispatchable_actions") or []
if not actions:
    raise SystemExit(f"Nothing to dispatch: {plan}")

print(actions[0])  # review before you confirm
action = cw.control.dispatch(env, actions[0], confirmed=True, mode="simulation")
cw.actions.wait(action["action_id"], twin_uuid=go2.uuid, timeout=60)
```
The environment needs a waypoint named "A". More in [Control agent](/ai/control-agent).
  </Tab>
</Tabs>

<Note>
Get an API key under [API tokens](/feature-reference/api-tokens). `cw.affect("simulation")` starts a MuJoCo instance, which uses [credits](/billing/credits); `"playground"` is free. Stuck? See [troubleshooting](/support/troubleshooting).
</Note>
