# Docs 10x refactor: what this branch does and what's left

Branch `claude/docs-10x-refactor`, based on `origin/dev` @ da10bc9. The full review, with five persona reports and scores, is in the "Cyberwave Docs — 10x Refactor Plan" doc.

## The idea

Cyberwave connects AI models to the physical world. Until now, no page said that and then showed how. This branch makes it the spine of the docs:

- the first line of the landing page;
- a tab of its own, organized by how a model reaches the robot: **See** (perception models), **Think** (LLMs and agents), **Act** (policies as controllers), **Automate** (no-code workflows) and **Learn** (record → dataset → train → deploy).

## In this branch

**Structure (`docs.json`)**
- 3 tabs become 4: **Docs** · **Robots** · **Tutorials** · **Reference**. All pages are placed, with no orphans and no duplicates. URLs don't move.
  - Docs follows the "Connect AI to robots" story. Its groups are Get started (ending with the Connect AI to robots overview), AI agents, AI models, Control, Learn, Run on edge or cloud, Platform, For integrators and Help.
  - **Control** lists five alternative ways to drive the robots in an environment: Manual input, Skills, Workflows, VLA models, RL policies. SmolVLA, OpenVLA-OFT and the VLA cloud node sit under VLA models. Workflows are split into core pages, Voice commands and Examples.
  - **AI agents** is organized by what they do for you: build the environment, control the robot, define workflows. MCP server and Claude skill move to Reference → AI developer tools.
  - **Robots** explains the idea first ("How hardware works": one twin model, capabilities rather than brands, support levels), then shows featured hardware by form factor.

## Documentation-wide audit (applied)

Three reviewers checked every hand-written page against the SDK and CLI source. The branch applies 413 verified fixes. By category:
- **Code:** 72 fixes. They include nonexistent calls (`cw.data.at`, `MqttTopicSpec`, `cw.api.create_mlmodel`, `cw.mlmodels.run(model=...)`, `twin.stop()`), wrong signatures, deprecated calls (`capture_frame`, `joints.get_all`), `cw.affect()` shown as free or called before `cw.twin()`, and CLI flags that don't exist.
- **Content:** 121 fixes. They cover TURN ports and the SFU (video is not peer-to-peer), token location ("Profile → Access"), environment variable names (`CYBERWAVE_BASE_URL`, `CYBERWAVE_MQTT_TOPIC_PREFIX`), Python 3.10+, 30 placeholder FAQ answers, broken anchors, internal ticket IDs, and descriptions over 160 characters.
- **Naming:** 220 fixes. They cover sentence-case titles, SO-101, Edge Core, digital twin, AI models, the agent names, and link text that matches each destination's title.
