<Info>
**Robot datasets first.** The playground currently supports LeRobot v2.1 and v3 datasets, imported from HuggingFace or uploaded as zip files. Playback for other dataset types (image classification, video, audio, multimodal) is coming in a future release.
</Info>

## Overview

The Dataset Playground lets you open an imported robot dataset in a structured viewer with:

- Synchronised episode video (wrist + external cameras)
- Low-dimensional data plots (joint positions, velocities, actions)
- A scrubbable timeline for frame-by-frame inspection

### Supported formats

| Format | Status |
|---|:---:|
| LeRobot v3 | ✓ Available |
| LeRobot v2.1 | ✓ Available |
| Other robot formats (RLDS, HDF5, Zarr, …) | 🔜 Coming soon |
| Image / video / CV datasets | — Not yet planned |

### Related API

- `GET /api/v1/datasets/by-slug`
- `GET /api/v1/datasets/{uuid}/episode-manifest`
- `GET /api/v1/datasets/{uuid}/resolve`

## Multi-format datasets

<Info>
**Robot datasets first.** The multi-format playground is being built specifically for robot manipulation and navigation datasets. Image, video, audio, and generic multimodal dataset formats are not in scope for the initial release.
</Info>

The multi-format playground extends the standard Dataset Playground with support for additional robot dataset formats beyond LeRobot, providing a unified viewer regardless of the original source format.

#### Supported formats (current & planned)

| Format | Status |
|---|:---:|
| LeRobot v3 | ✓ Available |
| LeRobot v2.1 | ✓ Available |
| Cyberwave OpenVLA | ✓ Available |
| RLDS / TF-Record | 🔜 Coming soon |
| HDF5 (Robomimic / ACT) | 🔜 Coming soon |
| Zarr (Diffusion Policy) | 🔜 Coming soon |
| GR00T | 🔜 Coming soon |
| Image / video / CV datasets | — Not in scope for initial release |
