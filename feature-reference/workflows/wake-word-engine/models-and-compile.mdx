Wake Word workflows only download the models the author selected — not every file in the openWakeWord catalog.

## Compile-time check (cloud)

When you **compile** or **sync** a workflow that contains a Wake Word Engine node, Cyberwave verifies that the selected models can be downloaded and loaded.

| Outcome | Meaning |
|---------|---------|
| Compile succeeds + warning | `openWakeWord models downloaded for edge: alexa, ...` |
| Compile fails | Wake word runtime unavailable, or download/network error |

## Generated worker (edge)

The generated worker downloads the selected models at import (before hooks run) and once more when the engine is created.

## Edge requirements

Edge operators can use the workflow's model requirements to confirm the worker image and cache contain the required weights: the `ml-wakeword` extra and the selected wake word models (e.g. `["alexa"]`). See [Edge workflow dependencies](/feature-reference/workflows/edge-dependencies).

## Edge worker image

The `cyberwaveos/edge-ml-worker` image pre-downloads all six built-in models at build time (~20 MB). Workflow-specific downloads still run for custom images.

## Custom images (air-gapped)

```dockerfile
RUN pip install openwakeword onnxruntime
RUN python3 -c "import openwakeword; openwakeword.utils.download_models()"
```

Or download only what you need:

```python
import openwakeword
openwakeword.utils.download_models(model_names=["alexa", "hey_jarvis"])
```

## Threshold vs compile

**Detection threshold** is a runtime node parameter (default **0.5**, one value for all selected wake words). It is embedded in the compiled worker. Changing threshold only requires **save → compile → sync** — no extra model download.

## After changing wake words or threshold

1. Save the Wake Word node in the editor (wake words and/or **Detection Threshold**).
2. **Compile** the workflow (validates models download).
3. **Sync** to the edge environment.
4. Restart the workflow worker container.
5. Confirm logs: `prediction_keys=['alexa']` (not `alexa_v0.1`) and `threshold=0.50` in init / detection lines.
