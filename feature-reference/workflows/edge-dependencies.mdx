Edge voice workflows need the right SDK extras on the edge worker. If a package is missing, compile/sync fails with an actionable error (for example: *"… is not installed"*).

| Layer | Where | Purpose |
|---|---|---|
| **1. Edge worker image** | `cyberwaveos/edge-ml-worker` | Runs the generated workflow; install matching `cyberwave[...]` extras |
| **2. Catalog** | Node and STT model requirements | Tells you which **one** SDK extra to install per node or STT model |

<Warning>
**Do not install `ml-all` on Raspberry Pi** unless you need every vision + STT + VAD runtime in one image. Catalog entries declare **one minimal extra** each (`ml-stt`, `ml-stt-faster`, …). Use `ml-all` only for CI or all-in-one images.
</Warning>

## SDK extras (`cyberwave-python`)

Install on edge with `pip install 'cyberwave[<extra>]'` or `pip install 'cyberwave-edge-core[<extra>]'` (thin passthrough).

| Extra | Packages | Used by |
|---|---|---|
| `ml-audio` | `silero-vad` | Audio Assistant |
| `ml-wakeword` | `openwakeword`, `onnxruntime` | Wake Word Engine |
| `ml-stt` | `pywhispercpp` | Call Model — Whisper.cpp catalog models |
| `ml-stt-faster` | `faster-whisper` | Call Model — Faster Whisper catalog models |
| `fuzzy-match` | `rapidfuzz` | Fuzzy Matcher |
| `zenoh` | `eclipse-zenoh` | Audio Track worker hook |
| `microphone` | `sounddevice`, `av`, … | Host mic capture (driver side) |
| `ml-all` | `ml-all-vision` + `ml-all-audio` (includes `torchaudio`) | **CI / all-in-one only** |
| `ml-all-audio` | `openwakeword`, `onnxruntime`, `pywhispercpp`, `faster-whisper`, `silero-vad`, `torchaudio`, `rapidfuzz` | Fat audio image (avoid on Pi) |
| `ml-all-vision` | `ultralytics`, `onnxruntime`, `opencv-python`, `tflite-runtime` | Vision-only fat image |

## Catalog STT models

Each public STT catalog entry requires **one** extra (never `ml-all`).

| Catalog model | Extra |
|---|---|
| Whisper Tiny EN Q5_1 | `ml-stt` |
| Whisper Base EN Q5_1 | `ml-stt` |
| Whisper Small EN Q5_1 | `ml-stt` |
| Whisper Tiny Multilingual Q5_1 | `ml-stt` |
| Whisper Base Multilingual Q5_1 | `ml-stt` |
| Faster Whisper Tiny EN | `ml-stt-faster` |
| Faster Whisper Base EN | `ml-stt-faster` |
| Faster Whisper Small EN | `ml-stt-faster` |

Hybrid models may fall back to the cloud whisper node when not running on edge.

See [Call Model STT on edge](/feature-reference/workflows/call-model-stt-edge).

## Edge worker image

Default `cyberwaveos/edge-ml-worker` installs a **fat** extra set:

`ml,ml-onnx,ml-stt,ml-stt-faster,ml-audio,ml-tracking,microphone,fuzzy-match,barcode,zenoh,image,schedule` plus `openwakeword` via `--no-deps` (Python 3.12).

For **Raspberry Pi**, rebuild a slim image with only what your workflow uses:

```bash
# whisper.cpp Tiny + VAD + wake word + fuzzy (no faster-whisper, no YOLO)
docker build \
  --build-arg CYBERWAVE_SDK_EXTRAS=ml-stt,ml-audio,fuzzy-match,zenoh,schedule \
  -f <edge-ml-worker Dockerfile> .
```

```bash
# Faster Whisper STT only
docker build \
  --build-arg CYBERWAVE_SDK_EXTRAS=ml-stt-faster,ml-audio,zenoh,schedule \
  -f <edge-ml-worker Dockerfile> .
```

## Typical voice pipeline (extras needed)

```
audio_track          → zenoh (+ microphone on capture host)
  → audio_assistant  → ml-audio
  → wake_word_engine → ml-wakeword
  → call_model (STT) → ml-stt OR ml-stt-faster (per catalog model)
  → fuzzy_matcher    → fuzzy-match
twin                 → base cyberwave
virtual_controller   → base cyberwave
```

Install the **union** of extras used in your graph — not `ml-all`.
