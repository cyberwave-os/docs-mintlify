---
title: "Send Depth node"
description: "Display depth estimates from a model on a twin."
---

**Send Depth** displays an upstream model's depth estimates on a twin in an edge
workflow. In **Call Model**, choose **Depth estimation**, select an available
model, and connect its camera image input.

## Typical chain

```
trigger (camera_frame)
  → call_model  (depth-estimation model)
  → send_depth
```

Pipe the same `call_model` output into `object_pose` when the model is
metric to lift 2D detections into 3D positions.

Relative depth is useful for visualization but does not measure distance. A
displayed point cloud does not establish calibration, localization or a map.

## Inputs

| Field | Type | Required | Description |
|---|---|---|---|
| `depth_map` | array | ✓ | H×W float32 depth map. Auto-wired when placed downstream of a depth-estimation `call_model`. |
| `twin_uuid` | string | ✓ | Twin on which to display the depth. |

## Parameters

| Field | Default | Description |
|---|---|---|
| `output_mode` | `normalized_uint16` | Normalized encodes a display range. Metric millimetres uses the model's actual distance scale; choosing it does not make a relative model metric. |
| `scale_factor` | `1000.0` | Applied only in `metric_mm` mode. Metres → millimetres by default. |
| `publish_every_n_frames` | `1` | Throttle. Set higher on tight uplinks. |

## Notes

- Edge-only. The node is filtered out of cloud workflows at compile time.
- Relative or unknown depth can remain visible, but cannot be used for metric
  depth recording or fusion. Use a metric model with confirmed output units for
  those steps, then configure camera calibration and the required spatial frames.
