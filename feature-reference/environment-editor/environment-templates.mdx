## Explore a use-case template

Template cards show the saved environment, included twins and workflows. Use the use-case filter and search to find a relevant setup. Public pages show public templates; signed-in users can also discover templates available through their existing access.

Open a card to inspect its contents. **Play tour** highlights twins at their saved positions in a lightweight schematic; **Next twin** steps through them manually. The tour is a visual preview, not a simulation result or a hardware command.

## Start using a template

Select **Use template**, sign in if needed, and choose the destination workspace or project in the existing creation dialog. Confirm the template to create your own environment. The source remains unchanged.

Cloning a setup does not provision physical hardware, establish edge connections or run its workflows. Review the copied configuration and connect the intended devices before operating the physical use case.

## Organize templates

With write access to an environment, open **Environment settings**:

1. Enable **Reusable environment template**.
2. Enter comma-separated **Use cases**, such as `material-handling, inspection`.
3. Save the settings.

Other tags you have added are preserved. The existing sharing controls determine who can discover and clone the template; marking an environment as a template does not make it public.
